🐸  Toad-ally Ready! Game Jam Project 🐸 
Play the game directly in your browser: https://raspberrycola.itch.io/toad-ally-ready

A cozy, 2D interactive puzzle game created from scratch during a 72-hour Game Jam. 
The player helps a frog get ready for a coffee shop date by completing a series of mini-games and tasks.

🛠️ Tech 
Engine: Unity 6000.3.10f1
Language: C#
Graphics: Custom 2D assets created in kleki.com
My Role: Solo Developer (Code, Art, Design)
